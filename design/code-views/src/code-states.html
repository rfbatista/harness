Code views: every block and state

The proposed blocks for reading code in the harness, drawn on the design system's tokens: code-layout, code-source-bar, segmented, file-tree, diff-summary, diff-view, code-view, code-lines, crumbs, change-mark, zone-tag and code-map, plus the tok-* syntax classes. Code sits in its own well (--color-code), mono 13px on a fixed 20px line. Colour marks the shape of the code and the kind of a diff line. A letter, a sign or a word carries every state.

Syntax tokens

The 17 tok-* classes of the contract. Nine have a colour. Variables stay ink, operators, punctuation and meta muted, headings bold, emphasis italic. Every colour clears 4.5:1 on the code well and on the add, remove and target washes, in both themes.

Change marks and zone tags

change-mark is a letter in a fixed slot: A added, M modified, D deleted, R renamed, C copied, T type changed, U untracked (dashed: git does not know it yet), and a dot for a directory with changes inside. zone-tag is a swatch plus a name. The hue is the bounded context's index in the map (8 hues, ≥ 3:1 as a graphic), dashed for a zone in no context. The dot-only variant is for the tree.

Source bar

Which code is on screen and whether it is current. On a session it is live, then stale, then gone. On a repository page it shows a fixed ref with its picker.

File tree

An ARIA tree, lazy: expanded, collapsed, loading (skeleton rows), selected (the open file), focused (roving tabindex, the ring inside the row), marks, zone dots, a symlink with its target, a submodule, a deleted file still listed so its diff can open, and a long name truncated with the full path in its title.

Changed files

diff-summary: totals, the scope switch (All · Branch · Working), one row per file with its mark, the path truncated from the start so the name stays, and its counts or a word. The file on screen is current. When the worktree is gone, All and Working are disabled and say why.

Diff

File heads stick while their hunks scroll. Lines carry + or − in the gutter (spoken as added or removed) as well as the wash. Withheld files say why and offer the next step. A renamed file reads old → new. The last line can say it has no newline. Split puts old beside new and wraps. It falls back to unified below a 44rem container.

File

code-view: a targeted range from the URL (#L45-L49), soft wrap, the truncated notice, binary and empty files, and loading. Line numbers are links, never copied with a selection, and stay put while the code scrolls sideways.

Map

code-map: an overview bar of each context's share, then one card per context with its zones, a bar and a count. Zones in no context get a dashed card, and unzoned files get their own last card. A project without zones shows an empty state that teaches.

Phone (375px)

One side at a time, like the session list and its detail. The changed files or the tree come first, and opening one shows it with a back control. Diffs are unified, the file head wraps, and rows are 44px on touch. The views switch stays at the top.
