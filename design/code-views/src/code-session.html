What this shows

Changes opens first on a session: the changed files beside the diff, scope All (branch + uncommitted) by default. The file the diff is scrolled to is current in the list. Files is the worktree as it is on disk, with change marks in the tree. Map divides the files into bounded contexts and zones. Every view, file, scope and line is a URL.

The Code tab lives in the session detail pane, which is about 49rem wide on a 1440px screen: the side list takes up to 18rem and the main side the rest. Expand (⇧E) gives the detail the whole width for reading. Below a 44rem pane (or on a phone) one side shows at a time, like the session list and its detail.

Try the state control: live follows the agent quietly. stale appears when a code_changed arrives for a file the person is reading: nothing moves under them until they press R. The changed-files list updates in place. gone falls back to the branch.
