Session pane — components (direction A)

High-fidelity components for the approved direction: the session head with its Checks button and panel, the ⋯ menu and its Delete confirm, the tab row's pane tools, the terminal without its bar, focus mode, narrow mode and the phone. Each frame is a real viewport (scaled to fit), drawn with the design system's own CSS. The new blocks are proposed below and are not in design-system/ yet.

1 · The page · desktop

Head 52px and tab row 40px, then the terminal down to the stream bar, which is the page's only footer. The terminal's own bar is gone: while live, the connection is the quiet dot at the end of the tab row. As in Phase 1, .screen holds the gutter and FitAddon measures its unpadded .host (L3).

  1. Session head .session-head: fixed height of 3.25rem whatever the session has. Inline padding is space-m, matching the tab row and the terminal gutter, so state, tabs and output start on one line.
  2. Checks button .check-button: a ghost, small button showing the loop's dot, the interval and when the next check is due. Shown only for a session with a check loop.
  3. Pane tools .pane-tabs > .tools: connection dot, Jump to latest (only while scrolled up), text size, focus mode.
  4. Terminal .terminal: no .bar. Its .screen fills the pane, and its last row is whole.

2 · Session head · states

The panel and the confirm open in the top layer (popover), so the head never grows and the terminal never resizes for them (L4). The panel and the menu follow the project's Dropdown/Menu keyboard rules: Esc closes them and focus returns to the trigger. The Delete confirm is an alertdialog: focus lands on Keep it and is trapped inside until it closes (Esc, Keep it, or Delete session), then returns to ⋯. The interval is the project's restyled native Select.

3 · Session head · when the column narrows

The head answers to its column (a session size container), not the window, so it adapts when the rail opens or the list sits beside it. Order of collapse: agent and age go first (< 46rem), then Git history moves into ⋯ (< 40rem), then the checks button keeps only its dot and interval (< 34rem). The title truncates last.

4 · Tab row · pane tools

The tools belong to a terminal tab: the App tab's run terminal gets the same set, and Design and Conversation get none. While the terminal is down, the tools collapse to a word and Reconnect. Reconnect focuses the terminal (F2). Jump to latest only scrolls and never takes focus. Focus mode is a button and never Esc.

5 · Terminal · states

Nothing floats over the output. Connecting is a word in an empty well. While down, the last screen stays, dimmed and frozen. An ended or failed session gets a note strip at the top of the pane with Resume session, and its last screen stays below, read-only. A session waiting on you gets an amber edge in the gutter. Keyboard focus in the terminal shows as a hairline inside the well.

6 · App tab, focus mode, narrow mode

The App tab's run terminal keeps its command row above it and gets the same tools. Focus mode hides the rail, the page toolbar, the list and the head. The top bar, the tab row (title, tools, Exit focus) and the stream bar stay. Below 64rem the list gives way to the open session, and the head leads with ‹ back.

7 · Phone

The session opens in place of the list and its head leads the screen. The head has two lines: ‹, the title and ⋯, then state · agent · age · checks. The tabs are 44px, with the connection dot at the end. Every action is in the ⋯ sheet, in 44px rows, and Delete asks again in a sheet. The stream bar shows its status only. The key strip is a later step.
