Projects list and project settings

Mockups for task "Project management", built with the real design-system CSS (design-system/css). Each screen is shown at 375px in the light and dark themes. On wider screens the same markup sits in the app shell beside the task rail.

  • /projects: every project with its live counts. J/K move, Enter opens, S opens settings, N new project, / filter.
  • /projects/{project}/settings: name and directory, ignored paths, links to Repositories, and the danger zone.

1 · /projects

One row per project, sorted by name. The status word says whether agents are working there now. Counts refresh live; a project created or renamed elsewhere shows up without a reload.

2 · /projects/{project}/settings

Shown here with a rename refused inline (PROJECT_NAME_TAKEN): the field keeps what was typed, and the message says what to do next. Saving is per section; nothing saves on blur.

3 · Deleting a project

Left: the confirmation. The Delete button stays disabled until the project's name is typed exactly. Right: the server refused with PROJECT_HAS_RUNNING_SESSIONS; the banner lists the sessions with links to their tasks.
