Select — native, restyled

Variant 1 of the dropdown catalogue. A plain <select> gets the system look with no class: a token-drawn chevron, the shared 32px / 5px / signal-focus control, a placeholder state, and three exceptions: data-size="sm", data-fit, data-variant="ghost". Where the browser supports customizable select, its open list takes the system's popover look automatically, with no API. The scripted variants (listbox select, combobox, menu) are in the Dropdown — listbox, combobox, menu card.

1 · Closed control: states

Default, placeholder (an empty first option is chosen), hover (edge and chevron go to ink), focus (signal edge + 1px halo), invalid (red edge, red halo while focused, error below), disabled (panel fill, faint ink and chevron), loading (disabled + aria-busy, the hint says it) and empty (one disabled option that says so).

2 · Sizes and the quiet variant

data-size="sm" is 26px and 13px type, for toolbars and board cards. data-fit sizes the control to its value instead of the row. data-variant="ghost" drops the fill and edge until hovered, for a filter sitting in a toolbar beside its title. A list box (multiple or size > 1) loses the chevron and marks chosen rows with the selection wash.

3 · Where it already lives

The call sites the web UI has today, unchanged markup apart from an optional data-size / data-variant: the top bar's project picker, the conversation filter in a toolbar, a board card's "Move to", the new-session form and the status-check interval.

4 · Phone width (375px)

Controls run full width, keep 32px (the OS picker opens on tap; iOS and Android draw their own list). The chevron and placeholder colour are what the person sees before the tap.

5 · The open list, where the browser allows it

Live: open them. Where appearance: base-select is supported (Chromium today) every single-value select draws its open list on the system's popover look, with no attribute and no API: raised, line-strong edge, 8px radius, Float shadow, 4px under the control, at least as wide and at most 24rem. Options are 32px plain text; hover and keyboard focus get the hover veil and a hairline ring, the chosen one the selection wash and a signal check. Groups use the quiet 12px heading. Elsewhere the OS list opens, so features never rely on it: options stay plain text, and rich options are the Listbox select's job.

6 · The open list, drawn

The same list as a static drawing, so it can be reviewed in any browser: the chosen row with its check, group headings, the row under the pointer, a disabled row.
